## Word Formatting Preset

| Setting | Value |
|---------|-------|
| **Font** | Times New Roman, 12 pt |
| **Line spacing** | 1.5 |
| **Margins** | 1" all sides, **1.5" left** |
| **Paper size** | A4 |
| **Binding** | Tape bound |

## Academic Integrity Rules

| Check | Accepted Threshold |
|-------|--------------------|
| **Similarity score** | **≤ 15%** (typical accepted score) |
| **AI score** | **< 20%** — high AI scores will be flagged |
