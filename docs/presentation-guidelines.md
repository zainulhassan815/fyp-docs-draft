# FYP Presentation (PPT) Guidelines

Prepare the Final Year Project presentation per the structure below.

- **Duration:** 7–10 minutes (per submission requirements)
- **Format:** `.ppt`
- **Submission:** Share the PPT on the department Google Drive link, and submit to
  **Ms. Ezzah** (see [deliverables-and-deadlines.md](deliverables-and-deadlines.md)).

## Required Slide Structure

| Slide | Title | Content |
|-------|-------|---------|
| 1 | **Title Slide** | **SCET logo**, project title, full name(s), roll number(s), Department of Computer Science, project guide name |
| 2 | **Table of Contents** | List 6–8 main sections |
| 3 | **Problem Statement** | One clear paragraph describing the problem |
| 4 | **Objectives** | 3–5 specific, measurable objectives |
| 5 | **Existing System & Literature Review** | Existing solutions and their limitations |
| 6 | **Proposed System & Architecture** | One clear system architecture / block diagram (**no paragraphs**) |
| 7–10 | **Implementation** | Tech stack, key screenshots, methodology flowchart / data approach (as applicable) |
| 11 | **Results & Output** | Actual results, test screenshots, charts, and findings |
| 12 | **Testing** | Table with test cases, expected results, and actual results |
| 13 | **Conclusion** | Refer to objectives — did you achieve each one? |
| 14 | **Future Scope** | 2–3 improvements possible with more time |
| 15 | **References** | 10 references in APA format |
| 16 | **Thank You** | Closing slide |

## Notes

- Slide 1 **must** include the **SCET logo**.
- Slide 6 should be diagram-only — avoid paragraphs of text.
- Keep the presentation well-rehearsed and compatible with the presentation system;
  keep a backup on USB and cloud storage for the
  [internal evaluation](internal-evaluation-circular.md).
